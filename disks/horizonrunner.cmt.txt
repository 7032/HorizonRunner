=== horizonrunner.t77 ロード手順 (FM-7 F-BASIC) ===

  エントリアドレス     : $0400
  実データ             : 24320 bytes (23.8 KiB)
  16 KiB チャンク数    : 2
  テープのパス数       : 2
  末尾ゼロパディング   : 8448 bytes

  最終メモリ配置:
    チャンク#0  -> $0400-$43FF
    チャンク#1  -> $4400-$83FF

  (PC 側で D77 -> T77/WAV/TXT を変換する手順はリポジトリの README.md を参照)

──────────────────────────────────────────────────
 操作手順 — 打つのはこの 1 行だけ
──────────────────────────────────────────────────

  RUN "CAS0:"

  テープの先頭に BASIC ローダーが載っている。 これを読んで
  走らせるだけで、 後は最後まで自動で進む。
  読み終わるとそのままタイトル画面が出る。

  読み込みに掛かる時間は 全部で 約 6 分 (334 秒)。
  プログラムから呼んだ LOADM は Searching / Found: を出さない
  ので、 この間は画面が止まったままに見えるが正常である
  (ローダーが最初に LOADING の案内を出す)。

  ローダーの中身 ("LOADER"):
      10 CLEAR ,&H13FF
      20 PRINT "LOADING - PLEASE WAIT ABOUT 6 MIN"
      30 LOADM "CAS0:"
      40 EXEC &H1400
      50 LOADM "CAS0:",,R

  ※ この 1 行版は実機のカセット入力での起動を確認済み
     (2026-08-15)。 うまく行かない場合は下の
     「手で打つ手順」 を使うこと。

──────────────────────────────────────────────────
 手で打つ手順 (1 行版が通らない時)
──────────────────────────────────────────────────

  ※ **ファイル名まで打つこと。** テープの先頭には BASIC の
     ローダー ("LOADER") が載っており、 名前を省いた
     LOADM "CAS0:" はそれに当たって Bad File Mode になる。
     名前を付けると Skip: LOADER と出して読み飛ばしてくれる

  CLEAR ,&H13FF

  [1/2] C01  チャンク#1
        LOADM "CAS0:C01"
        EXEC &H1400
        ; 読み込みに約 3 分 (158 秒) 掛かる。
        ;   Found: C01 が出た後は画面が止まったままだが、
        ;   テープが回っている間は正常。 Ready が出るまで待つ
        ; トランポリンの動作:
        ;   $3C00-$5FFF -> $6000-$83FF  9216 byte (後方)
        ;   $2000-$3BFF -> $8400-$9FFF  7168 byte (後方)
        ;   ($8400 は裏 RAM の退避枠。 最終パスが $4400 へ戻す)
        ;   ROM オーバレイを戻して RTS (= F-BASIC へ復帰)

  [2/2] C02  チャンク#0, 最終
        LOADM "CAS0:C02",,R
        ; 読み込みに約 3 分 (176 秒) 掛かる。
        ;   Found: C02 が出た後は画面が止まったままだが、
        ;   テープが回っている間は正常。 Ready が出るまで待つ
        ; トランポリンの動作:
        ;   $2000-$5FFF -> $0400-$43FF  16384 byte (前方)
        ;   $8400-$9FFF -> $4400-$5FFF  7168 byte (前方)
        ;   LDS #$FBFF / JMP $0400

──────────────────────────────────────────────────
 補足
──────────────────────────────────────────────────

  - CLEAR ,&H13FF で MEMSIZ を $13FF に下げ、
    $1400-$7FFF をユーザ作業域として確保する

  - 各 LOADM ブロックは単一連続 ($1400-$5FFF) で構成:
      $1400-$1419  Stage 1                      (26 B)
      $141A-$141F  復帰小片                      ( 6 B)
      $1420-....   Stage 2 source + 移動表
      ....-$1FFF   ゼロパディング
      $2000-$5FFF  16 KiB バッファ

  - Stage 1 は IRQ マスク + ROM OFF + Stage 2 と移動表を
    $D000 (裏 RAM) へコピーして JMP。Stage 2 は移動表を
    そのとおり実行し、最終パスなら LDS + JMP entry、
    中間パスなら $141A の復帰小片へ跳ぶ

  - 復帰小片が低位 RAM ($141A) に居るのは、
    $D000 が ROM オーバレイの下だからである。そこで
    オーバレイを戻すと次の命令が ROM から取られてしまう

  - 裏 RAM の退避枠は $8000-$EFFF から
    切り出す (ROM オーバレイ OFF で素の RAM になる領域)。
    最終配置・トランポリン・スタック予約を除いてから配るので、
    退避したかけらを後続のロードが踏むことはない

  - EXEC は必ず明示的にアドレスを指定すること
    (引数なし EXEC は実機で挙動が不安定)

  - 1 行打つごとに Ready が出るのを待ってから次を打つこと。
    前の行の処理中に打った文字は取りこぼされる

  - デバイス名は "CAS0:" と必ず明示して打つこと。
    デバイス名を省いた LOADM "",,R は使わない
    (実機で Missing Operand になり読み込めなかった)

  - 綴りを間違えたときの出方 (いずれも実測):
      "CAS:"    0 落ち          -> Bad File Descriptor
      "CASO:"   0 が英字の O    -> Device Unavailable
      "CAS0"    : 落ち          -> CAS0 という名前のファイルを
                                   探し続け、 Skip: を繰り返して
                                   いつまでも止まらない
      CAS0:     引用符が無い     -> Type Mismatch
    どれも打ち直せばよい。 テープを頭から巻き戻すこと
